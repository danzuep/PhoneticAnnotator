Unihan uses the bundled Unicode 18 character readings, not a morphological dictionary. First-reading selection is a heuristic, not contextual disambiguation; uncheck it to preserve ambiguous candidates in JSON. Unknown text is preserved.

The word dictionary contains examples: 食べる, 你好, 重庆, كتب; upload TSV files to extend it. Unihan is downloaded once (about 8.5 MB); only the selected field is indexed in memory. Historical Tang/fanqie readings and definitions are omitted. Data and runtime notices.
