.NET WASM local profiling

This standalone page starts the module worker only when you run it. Serve the published wwwroot over HTTPS on real devices (including LAN devices; never disable browser security). Cache comparisons require secure-context storage; localhost HTTP also works for local testing. Desktop/mobile browser emulation is not a physical-device measurement.

Each run clears this site's dictionary application cache, measures that pass, then measures a warm application-cache pass. Both use fresh workers. Browser HTTP/runtime caches are not cleared: “cold dictionary cache” does not mean cold network, browser, or runtime. Network access is only to the bundled same-origin runtime and dictionaries; no results are uploaded.

Annotation timings are sequential worker round trips including messaging, .NET interop and managed JSON serialization, not managed-only nanosecond timings. Warmups are excluded. Synthetic repeated tweet/article/chapter workloads are not natural-language benchmarks. Korean/Thai use deterministic in-memory TSV supplements when absent from the bundle; Unihan uses actual bundled readings.
